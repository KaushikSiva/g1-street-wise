# STREETWISE asset provenance

- **G1 robot:** official Unitree `g1_12dof.urdf`, its STL visual meshes, companion MuJoCo XML, and `motion.pt` LSTM policy. Repository `unitreerobotics/unitree_rl_gym`, revision `276801e46c5d433564f24658bac64f254b7d2d4b`, BSD-3-Clause. The viewer loads the URDF directly and applies recorded joint angles by name. The simulator uses Unitree's matching MJCF deployment model. Base policy weights remain unchanged.
- **SDK:** `unitreerobotics/unitree_sdk2_python`, revision `65691c8a8bc53b98d3976dba4dbf9d5d20b2e7f5`, BSD-3-Clause. Cyclone DDS 0.10.2 is built locally; transport verification uses domain 42 and loopback, never a physical robot.
- **Human FBX:** Microsoft Rocketbox `Male_Adult_01` and compatible `m_walk_neutral.max.fbx`, revision `0943055db6ec570bcef9f2c8b41c9e5467c808f9`, MIT license. Natural human proportions, striped polo, shorts and shoes. The original body/head textures and skeleton are retained; the supplied compatible walking clip is applied in place and exported with embedded textures by `scripts/fork/robot/prepare_pedestrian.py`. License is included beside the runtime asset. [Official library](https://github.com/microsoft/Microsoft-Rocketbox). Human animation is illustrative; world position follows the simulator's synthetic actor. It is not a learned human-motion model or a scanned Chennai pedestrian.
- **Moving car:** existing original CC0 `encaarpus-parked-car.glb`, reused as a moving hatchback and scaled to the simulator's rectangular car envelope. Its photo-informed shape is not a verified make/model replica. The path is synthetic.
- **Van:** existing detailed `central-avenue-passenger-van.glb`, made in Blender from the user's Central Avenue photo references before this hackathon. Includes modeled bodywork, glazing, wheels, lighting, trim and interior. Shape/class is photo-informed; exact vehicle make, dimensions and hidden surfaces are inferred. Scaled to the explicitly modeled 4.7 × 1.7 × 2.15 m occluder envelope. This is a full mesh asset, not a measured scan.
- **Map and facades:** existing OpenStreetMap footprints and photo-informed Chennai scene. Attribution: © OpenStreetMap contributors. Map and facade work predate FORK. The runtime does not redistribute private source photographs.
- **Surface textures / daylight HDR:** reused licensed assets listed in `public/assets/textures/manifest.json`; Poly Haven assets are CC0. These are material/light references, not surveyed Central Avenue pixels.

Human and van are visual assets above synthetic simulator geometry. Their paths, scale and obstacle envelope must agree with the recorded experiment. No generated footage is presented as a simulator result.
